## 1. The ComfyQ workspace

The workspace icon at the top of the bar adds a **ComfyQ** tab (once per file; afterwards it just switches to it):

```
┌──────────────────────────────┬──────────────────────────┐
│ camera view + the bar        │ the frame (renders,      │
│                              │ results, painting)       │
├──────────────────────────────┴──────────────────────────┤
│ the ComfyQ graph                                        │
├─────────────────────────────────────────────────────────┤
│ timeline                                                │
└─────────────────────────────────────────────────────────┘
```

The strip at the top of the bar switches what you are doing:

| Mode | What happens |
|---|---|
| **Frame** | the frame shows the latest render or result; camera view |
| **Draw** | paint on the frame (a copy, "ComfyQ Frame", so a new render cannot erase it), or *Sketch in Camera View* |
| **Mask** | the ComfyQ Mask tool in the camera view, or *Paint Zone on the Frame* |
| **Graph** | the graph fills the screen; *Back to Previous* (top bar) returns |

A file saved with the first layout (graph and timeline side by side) keeps it as "ComfyQ (old layout)"; the button
adds the new one.

## 2. Draw what you want: the Sketch

- Set an image input to **Sketch** (bar), or add a **Sketch** node (graph › Scene), and press **Start Sketch**:
  Blender's pencil, in the camera view, in front of the scene. **Tab** when done.
- **Sketch Only** sends the drawing alone on white; otherwise it is drawn over the clay scene.
- Say in the prompt what the lines are: "the circle with a basket in the sky is a hot-air balloon".
- Ordinary scene renders never include the sketch.
- Class presets: *Sketch → photoreal (FLUX.3 Klein edit)*, *Sketch Only → picture (Qwen canny)*, *Sketch → video
  (FLUX.3 Klein + LTX 2.5)*.

Tested on the GPU (cliff house): a balloon and a stick figure became a red and white balloon and a person on the
roof; the video version (2.5 min) has the person waving and the balloon floating, with sound. LTX did not keep the
camera still although asked. Pictures: `live_check/sketch/`.

## 3. Change only part of the picture: masks

With the mask input on **Render + Mask Zone**:

- **Find by name**: type "sofa" (several names: commas) and press ▶; SAM3 finds it in the camera view (about 30 s).
  Untick a name to leave it out.
- **Mask Tool**: click objects, drag a box, Shift+drag a free shape, Ctrl to cut.
- **Paint Zone** (mask source *Painted Zone*, or the workspace's Mask mode): paint over what to replace with
  Blender's Erase Soft brush; it turns transparent.
- **Grow** gives room for a bigger new object; **Feather** softens the edge; **Render Mask** shows the zone in red.
- Class preset: *Find and replace an object (SAM3 + Flux2 Klein inpaint)*.

Tested on the GPU (living-room demo): "sofa" found in 30 s; the inpaint changed only the sofa (emerald velvet,
brass legs), 30 s. Pictures: `live_check/mask_find/`.

## 4. Fixes from the UI/UX audit (phase 6)

- **Safer:** ✕ on a job asks "Cancel Job?"; an Import node's *Replace* keeps objects you moved; nothing can be booked
  while the server is switching models.
- **Clearer:** when ComfyQ is not serving yet, Blender waits for the teacher and **connects by itself**; old notes
  leave the bar after 2 minutes; node errors wrap and say what to do ("Not Served: Ask the Teacher", "Press ⟳ to try
  again"); model names instead of job ids and "Workflow.002"; each Add-menu item explains its node.
- **Graph:** each Scene Render / Mask / Sketch node shows its own render; new nodes never land on others; **+ next to
  Shot** makes a shot (no hidden Ctrl+B); the header shows **Add** and **Presets** instead of nine bare icons.
- **Teacher's Server panel:** **Stop Serving...** (X) on extra models, a red "Solo is on" line, readable names.
- **Job cards:** importing a 3D result asks Place / On the Ground / Size; long errors wrap.
- **Presets** now follow the scene's 16:9 shape (several came out square or portrait).
- Library presets fixed: Wan 2.2 key-frames (all three motion prompts), Qwen relight (object in the right slot),
  Ideogram (How to use: keep its JSON caption).
