# Architecture AI render: segmentation → labelled prompt → render → upscale

Start from a blocked-out scene modelled in Blender, find its surfaces with **SAM3**, name each surface and
its material in the prompt, render it photoreal, repaint single surfaces if needed, upscale.
Tested 2026-10-04 on `E:\zaki\arch_room.blend` (generated by `tools/make_arch_scene.py`: a living room of
boxes: floor, three walls with a window and a door, ceiling, sofa, table, rug, shelf, pendant lamp).

## The chain (what was chosen, and why)
| Step | Workflow / tool | Time (RTX 5090) | Choice |
|---|---|---|---|
| Base render | Cycles still, 1920×1080, 96 samples (`blender_render style=CYCLES`) | ~6 s | the GPU is free again after it |
| Segmentation | `utility_video_segment_sam3`, one job per phrase (`blender_segment`) | 12 phrases ≈ 4 min | all 10 surfaces found, clean edges |
| Render | **Qwen Image 2.1 edit** (`image_qwen_image_2_1_image_edit`, 30 steps) | 57 s | **best**: keeps the geometry almost pixel for pixel (masks still line up), 1920×1088, door + shelf kept |
| | Qwen 2.1 depth control (2 MP, 30 steps) | 93 s | very good, more photographic light; layout kept |
| | Flux2 Klein 9B edit | 25 s | fast, nice, but ~1 MP and changed the layout (the shelf box became a bookcase **and** an extra door) |
| One surface | **Flux2 Klein inpaint** + the SAM3 floor mask (`blender_mask_image`) | 32 s | only the floor changed (plank → herringbone), the rest untouched |
| Upscale | **PiD ×4** (`utility_pid_image_upscale`) | 34 s | **best**: faithful colours, believable wood grain/book detail, 7616×4320 |
| | SeedVR2 7B int8 (×4, colour "lab") | 65 s | sharper but invents jagged fake lettering and a screen-door pattern on the bookcase |

Model switches (solo, ComfyQ restart or lane): ~50–70 s each.
Result files (local, gitignored): `live_check/arch/` (state.json, base_cycles.png, each candidate, refine_floor,
up_pid, up_seedvr2_7b, upscale_compare*.jpg) and the masks/overlay in
`%LOCALAPPDATA%\comfyq-bridge\cache\segment\arch\`.

## SAM3 in ComfyQ: what to know
- The workflow is **video only** (video + text → mask video). The bridge turns a still into a 3-frame MP4
  and reads the middle mask frame back (Blender's own sequencer/FFmpeg, "Standard" colours).
- **One surface per phrase**: "wall" found only the back wall; "left wall" / "right wall" the side walls.
  A lower threshold (0.3) did not help. Labels can therefore be phrase groups:
  `"wall|left wall|right wall"` → one "wall" label, the union of the three masks (the default does this).
- Short concrete nouns work: floor, ceiling, window, door, sofa, table, rug, shelf, lamp were all exact on
  the blocked-out render (even the unlabelled brown box: "shelf").
- One job per phrase, all booked at once; ~20 s each on the 5090.

## The labelled prompt
`surfaces.surface_prompt` lists the found surfaces, biggest first, with their material:
> Photorealistic interior photograph of a modern living room, architectural photography, natural daylight
> through the window, soft realistic shadows. The wall is smooth warm-white lime plaster. The ceiling is flat
> white plaster. The floor is wide-plank light oak parquet with a satin finish. The rug is a cream hand-woven
> wool rug. The shelf is a walnut bookcase with books and ceramics. The window is a black steel-framed glazing
> looking onto a sunny garden. … Keep the exact layout, camera, perspective and proportions of the room.

Surfaces without a material are still named with where they are ("The column (left).") so the model keeps them.
For Qwen edit the prompt starts "Turn <image1>, a 3D render, into a real photograph."

## Using it
- **Agent (MCP)**: `blender_segment` (labels, materials, intro, outro → masks, overlay in the Image Editor,
  `prompt`) → `comfyq_submit` Qwen edit with the Cycles render + `prompt` → `blender_mask_image` (render + a
  surface mask) → `comfyq_submit` Klein inpaint → `comfyq_submit` PiD → `blender_import`. Needs each model served
  (teacher tools / solo).
- **Students (graph)**: class preset *Architecture: Cycles render → photoreal → 4× upscale (Qwen edit + PiD)*
  (edit the materials in its Prompt node).
- **Headless, step by step** (what produced the table): `tools/arch_render.py <scene> <out> base | segment |
  render | refine --from=<png> --labels=floor --material="…" | upscale --from=<png>`.

## Limits / next
- Segmentation is not in the graph yet (no SAM3 node): the prompt node is filled by hand or by an agent.
- Qwen outputs 1920×1088 (over ComfyQ's 1920×1080 upload box): masks and uploads are shrunk to 1904×1080.
- Blender knows the exact surfaces (object/material IDs): a Blender ID-mask pass would be exact and free;
  SAM3 is the right tool when the picture is not from Blender (photos, AI renders) or names are missing.
